## Technical Decisions Made

### 1. Simple Provider Pattern Over StateNotifier
**Decision:** Use simple `Provider<AuthActions>` instead of `StateNotifier<AsyncValue<void>>`
**Reason:** StateNotifier added complexity without benefit; UI components manage their own loading state
**Trade-off:** Less centralized state, but simpler and more explicit

### 2. Offline-First Initialization
**Decision:** Initialize Supabase conditionally based on environment variables
**Reason:** App must work without cloud; users can choose offline-only mode
**Trade-off:** Two code paths to maintain (with/without Supabase)

### 3. Skip Automated Tests for Auth Layer
**Decision:** Skip writing auth tests due to environment issues
**Reason:** Time vs value trade-off; integration tests more valuable
**Trade-off:** No automated verification; must rely on manual testing
**Mitigation:** Code passes static analysis; can add tests later
